# 默认公众号排版风格

用户确认的参考文章为《成年人的四次元：给生活装一个“哆啦A梦”的口袋》：
https://mp.weixin.qq.com/s/FqVv36rLkHTrZy1tyw1j2Q

2026-10-05 已读取正文、计算样式和顶部视觉；没有逐张检查全部图片模块。此记录可用于后续排版，不必每次重新访问旧页面。新参考优先。

| 元素 | 默认参数 |
| --- | --- |
| 页面 | 白底，流式单栏，移动端无横向滚动 |
| 正文 | 深灰 `#3E3E3E`，16px，行高 1.6，字距 0.544px |
| 字体 | `Optima-Regular, PingFangTC-light, PingFang SC, Microsoft YaHei, sans-serif` |
| 对齐 | 普通段落两端对齐；英文或混排过密时左对齐 |
| 强调色 | 暖黄 `#FFCA00`，用于少量关键词、短句和线条 |
| 重点短句 | 24px，行高 1.6，适当右对齐或居中，增加上下留白 |
| 图注 | 12px，行高 1.6，灰色 `#A0A0A0`，居中 |
| 段落间距 | 起点 18px；段落转换约 28–38px；随文章调整 |
| 封面方向 | 白底和暖黄块面，手写感黑字，贴纸/纸张拼贴元素 |

阅读节奏：短段落展开，重点句独立呈现，图片连接不同段落，再进入适合本文的案例或行动模块。模块数量由内容决定；没有活动或案例时不要虚构。

封面拼贴和手写字属于图片视觉，不用复杂 CSS 模拟成公众号正文。标题可后期叠字以保证准确；不同设备缺少指定字体时会使用后备字体。

当主题是专业或技术文章时，沿用色彩、字号、留白和图注系统，按内容使用标题、解释与图表，不强行改写成生活叙事。
