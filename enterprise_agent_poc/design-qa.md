## 范围

- 正式页面：登录、工作台、AI 创作、我的生成、企业知识库、企业素材库、企业设置、成员管理、使用与计费、个人中心。
- 组件状态：右上角用户账户 Dropdown。
- 目标桌面视口：1440px。
- 参考设计稿：`F:/谷歌下载/01-login.png` 至 `09-billing.png`，以及 `F:/谷歌下载/ChatGPT Image 2026年9月9日 11_03_38.png`。

## 已完成的可验证项

- 登录页在本地浏览器可访问，账号、密码、登录按钮和禁用的第三方登录占位均可从无障碍树识别。
- 前端脚本语法检查与 Python 自动化测试通过。
- Lucide 已本地静态打包，不依赖外部 CDN；图标按钮均具有可读标签或可见文本。
- 用户菜单包含悬停、点击固定、外部点击关闭和 180ms 离开延迟，避免头像与菜单之间移动时闪退。
- 个人中心不展示未由 API 提供的手机号、设备或最近登录等数据；编辑资料和修改密码是明确禁用状态。
