# Workbench V1｜普通产品 API 缺口

本文只列出设计稿要求、而现有普通产品 API 尚未提供的能力；不涉及 Codex Runtime、DeepSeek、MCP 或 Skill 核心。

## 1. 成员管理

- 成员列表、邀请、编辑角色、启用/禁用。
- 成员统计、成员搜索和角色/状态筛选。
- 建议资源：`/api/v1/members`、`/api/v1/members/{id}`、`/api/v1/members/invitations`。

## 2. 知识文件上传与处理

- multipart 上传 PDF/DOCX/TXT/MD。
- 文件大小、MIME、处理阶段、失败原因、重试和下载/预览。
- 当前仅支持文本录入，不能将设计稿的文件上传按钮伪装成可用。

## 3. 素材二进制上传与编辑

- 对象存储预签名上传或应用代理上传。
- 素材封面、标签编辑、元数据编辑、文件大小和来源。
- 当前 API 可创建 URL 型素材并删除，未提供上传、编辑和标签筛选服务端接口。

## 4. 计费与积分明细

- 积分流水、时间范围统计、按模型/成员聚合、趋势数据。
- 充值订单、套餐、发票和支付状态。
- 当前仅可读取积分余额；前端已禁用充值与套餐动作。

## 5. 工作台内容

- 平台公告管理/读取。
- Agent 可用性与“即将上线”能力清单。
- 当前工作台只展示真实的 image-agent，其余保持不可用。

## 6. 个人资料与账号安全

- `GET /api/v1/me` 已可读取当前登录用户自己的展示名、邮箱、企业名称、租户与角色，个人中心据此展示真实身份资料。
- `PUT /api/v1/me` 已支持当前用户更新头像、姓名和邮箱；头像限制 PNG/JPG/WebP、最大 2MB，并存入私有对象存储。
- 手机号尚无可信数据源，V1 前端不展示或伪造绑定状态。
- 仍缺少 `PUT /api/v1/me/password`：校验当前密码、设置新密码、使其他会话失效并记录安全审计事件。
- 最近登录设备、手机号/邮箱绑定状态尚未有可信数据源，V1 前端不展示或伪造这些信息。
