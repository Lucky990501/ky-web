# Skill Registry V1｜Stage 5 生产验收测试积分发放记录

验收日期：2026-09-11

## 背景

Skill Registry V1 图片 Agent 真实 Turn 验收所需余额高于生产验收账号的执行前余额，无法提交图片生成任务。当前产品尚未实现在线充值 API 或平台积分管理后台，UI 中充值按钮处于禁用状态。

## 授权目标

用户明确要求将余额调整到指定测试额度，而不是在原余额上额外增加同等额度。生产 Tenant、账号和精确额度不写入公开仓库。

## Dry-run

| 项目 | 值 |
| --- | --- |
| 当前余额 | 已核对，低于单次图片任务成本 |
| 目标余额 | 已按用户明确要求核对 |
| 应增加 | 由目标余额减当前余额计算 |
| 审计流水冲突 | 0 |

Dry-run 只读取积分账户与流水表，没有修改余额。

## 执行

使用单条事务性 PostgreSQL CTE：

1. 锁定 Tenant 积分账户；
2. 写入一条正向积分流水；
3. 使用同一流水金额更新账户；
4. 任一步失败则整体回滚。

审计信息已在生产侧保存，包括唯一 transaction ID、正向 amount、验收 reason 和执行账号。为避免向 GitHub 暴露生产运营数据，本报告不记录其具体值。

## 执行后验证

- Tenant 余额：与用户指定目标一致；
- 对应审计流水：1 条；
- 审计流水金额：与实际余额增量一致；
- 重复流水：0；
- 当前余额足以继续本轮图片 Agent 生产验收。

## 已知事项

当前“充值”只完成了本次生产验收所需的受控测试额度发放，不代表支付、套餐、退款、对账或平台积分运营后台已经实现。正式商业充值能力需要独立产品设计、权限模型、幂等 API 和财务审计 Gate。

## 结论

**PASS。** 生产验收测试积分已按目标余额准确发放，账户与审计流水一致，可以继续图片 Agent 真实 Turn。
