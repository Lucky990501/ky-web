# 锟元 AI 工作台

这个目录是锟元 AI 工作台在 `Lucky990501/ky_dph` 中的产品层，不修改 DeepSeek Harness 的核心包。

## 职责

- `static/`：登录用户使用的锟元 AI 工作台界面，包括智能体创建、对话和运行记录。
- `runtime/`：服务器侧 Harness 受限运行配置。它关闭终端、文件、联网搜索和子智能体工具，只保留文本智能体能力。
- `docs/`：官网与工作台之间的接口约定。

官网项目只保留品牌页面、官网登录和工作台入口。工作台项目负责智能体、运行时和后续的知识库、工具策略与业务能力演进。

每个用户拥有独立的 AI 额度。工作台在执行任务前由官网后台原子扣减 1 次额度；余额不足时拒绝执行，运行失败时自动退回。管理员可在官网管理后台的“用户档案”中手动调整额度。

## 部署边界

`ai.luckio.cn` 静态站点使用 `static/`，工作台 API 由独立控制面服务提供。控制面与官网使用同一个用户数据库；官网签发短时 SSO Cookie，工作台只校验 Cookie，不接收或保存官网密码。

模型凭据只存放在服务器的 `/etc/kunyuan-runtime/model.env`，绝不提交到仓库。
